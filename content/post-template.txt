## 핵심 내용

직접 이해한 내용을 자신의 말로 설명한다. 제목은 화면에서 자동으로 표시되므로 본문 제목은 `##`부터 작성한다.

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, blog!\n";
}
```
