## 현재 내가 중요하게 생각하는 것

최근 나는 시스템 해킹과 임베디드 시스템 보안에 관심을 바탕으로 IP 카메라 펌웨어 분석, 자동차 퍼징 프로젝트를 하고 있다. 프로젝트를 진행하면서 기술을 배우는 것뿐만 아니라, 앞으로 어떤 기준으로 진로와 활동을 선택할 것인지 생각하게 되었다.

내가 중요하게 생각하는 기준은 전문성, 사회적 기여, 의미와 보람이다. 이 가운데 가장 중요하게 생각하는 것은 전문성이다.

### 1. 전문성

내가 생각하는 전문성은 도구의 사용법이나 정해진 분석 절차를 아는 것에 그치지 않는다. 분석 대상이 어떤 구조로 동작하는지 이해하고, 문제가 발생한 원인과 실제 영향을 스스로 설명할 수 있는 역량을 갖추는 것이다.

현재 진행 중인 IP 카메라 펌웨어 분석에서도 외부 입력이 내부의 어떤 서비스와 함수를 거쳐 처리되는지 파악하는 데 어려움을 겪었다. 부족한 지식을 보완하기 위해 펌웨어의 부팅 구조와 내부 서비스를 공부하고, 공개 펌웨어의 운영체제와 바이너리를 분석하며 전체 구조를 파악하고 있다. 이 경험을 통해 현재 무엇을 알고 있는가보다 부족한 부분을 찾아 자신의 역량으로 만들어가는 과정이 중요하다는 것을 배웠다.

### 2. 사회적 기여

나는 진로를 선택할 때 내가 가진 기술이 사회에 어떤 영향을 줄 수 있는지를 중요하게 생각한다. 임베디드 시스템의 보안 문제는 사용자의 안전과 개인정보에 직접적인 영향을 줄 수 있기 때문이다.

앞으로 다양한 임베디드 시스템의 취약점을 분석하고 보안 사고를 예방하는 연구자가 되고 싶다. 취약점을 발견하는 데서 끝나지 않고 근본 원인과 실제 영향을 검증하여 구체적인 개선 방안을 제시함으로써, 사람들이 일상 속 기술을 더 안전하게 사용할 수 있도록 기여하고 싶다.

### 3. 의미와 보람

나는 주어진 일을 끝내는 것보다 내가 만든 결과가 실제 문제를 해결하는 데 사용될 때 보람을 느낀다. 분석 결과가 보고서나 개선 방안으로 이어지고, 실제 취약점을 줄이는 데 도움이 되는 경험을 하고 싶다.

새롭게 알게 된 내용과 시행착오를 기록하고 공유하는 것도 의미 있는 결과라고 생각한다. 나의 다음 분석에 도움이 될 뿐만 아니라 비슷한 문제를 겪는 다른 사람에게도 참고 자료가 될 수 있기 때문이다.

## 나이츠프론티어에 지원한 이유

IP 카메라 펌웨어를 분석하면서 웹 서비스와 네트워크 기기의 통신 구조, 외부 입력의 처리 과정을 추적하는 방법에 대한 이해가 부족하다는 것을 알게 되었다. 혼자 자료를 찾아 공부하는 것만으로는 내가 놓친 부분을 발견하거나 다양한 분석 방법을 접하는 데 한계도 느꼈다.

나이츠프론티어에서는 다른 교육생과 수료생의 경험을 배우고, 버그바운티·개발·리서치 등 다양한 미션을 통해 하나의 보안 문제를 여러 관점에서 바라보고 싶다. 부족한 지식을 실제 분석에 적용하고, 같은 관심사를 가진 동료들과 함께 신규 취약점 발굴에 도전하고 싶어 지원했다.

## 7개월 동안 이루고 싶은 것

첫 번째 목표는 IP 카메라와 같은 네트워크 기기를 대상으로 공격 표면 식별부터 취약점 검증과 보고까지 전체 분석 과정을 스스로 수행할 수 있는 역량을 갖추는 것이다. 새로운 펌웨어를 접했을 때 외부 입력의 처리 과정을 추적하고, 관련 서비스와 바이너리를 선정하여 분석 방향을 세우며, 발견한 취약점의 원인과 영향을 검증하고 싶다. 최종적으로는 분석 결과를 보고서로 정리하여 버그바운티나 취약점 제보로 연결할 수 있도록 성장하는 것이 목표다.

두 번째 목표는 AI를 활용해 문제를 효율적으로 해결하는 역량을 기르는 것이다. CTF에서 같은 AI를 활용하면서도 나보다 더 빠르게 문제를 해결하는 참가자를 보며, 중요한 것은 도구 자체보다 문제 해결 과정을 얼마나 잘 이끌어가는가라는 점을 느꼈다. 나이츠프론티어에서는 AI가 올바른 방향으로 문제를 해결하고 있는지 점검하고, 병목이 발생했을 때 잘못된 가정이나 누락된 정보, 접근 방법의 문제를 빠르게 찾아 수정하여 올바른 해결 경로로 돌아오는 능력을 기르고 싶다.

세 번째 목표는 자동차 보안을 더 깊게 파고들지, 보다 넓은 임베디드 시스템 보안을 중심으로 진로를 정할지 방향을 구체화하는 것이다. 자동차 퍼징 프로젝트를 통해 자동차 도메인에 대한 지식을 어느 정도 얻었지만, 공부할수록 자동차 관련 전공자만큼 도메인을 깊이 이해하고 있지는 않다는 점도 느꼈다. 7개월 동안 여러 분야의 미션을 수행하고 교육생과 수료생의 경험을 들으면서, 부족한 도메인 지식을 보완해 자동차 보안을 전문화할지 다른 임베디드 분야로 관심을 넓힐지 판단할 근거를 얻고 싶다. 하나의 진로를 성급하게 확정하기보다 내가 지속적으로 탐구하고 전문성을 쌓을 수 있는 영역을 찾고, 이후의 학습 방향을 구체적으로 세우는 것이 목표다.

## 나이츠프론티어에서 해보고 싶은 경험

### 취약점 탐색부터 검증과 보고까지 완주하는 경험

버그바운티 미션에서 공격 표면을 찾고 취약점 가능성을 탐색하는 과정을, 개발 미션에서는 서비스의 구현 구조와 데이터 흐름을 이해하고 수정 가능성을 검토하는 과정을 경험하고 싶다. 각 미션에서 배운 방법을 연결하여 현재 진행 중인 펌웨어 분석에도 적용하고, 하나의 문제를 발견하는 데서 그치지 않고 근거를 갖춰 설명할 수 있는 분석 역량을 기르고자 한다.

특히 버그바운티 미션을 수행하며 실제 분석 대상에서 취약점을 탐색하고 검증하는 전 과정을 주도해보고 싶다. 발견한 문제의 재현 방법과 근본 원인, 실제 영향, 대응 방안을 다른 사람이 이해할 수 있는 분석 보고서로 작성하고 피드백을 받으며 보고서의 완성도를 높이고 싶다. 최종적으로는 직접 분석한 취약점을 제보하여 취약점 제보 이력을 남기는 것이 목표다.

### 대면 합숙과 팀 활동을 통한 협업 경험

합동강화훈련에서 다른 교육생들과 함께 문제를 해결하면서 서로의 분석 방법을 비교하고, 각자가 가진 강점과 부족한 부분을 이해하고 싶다. 막힌 지점과 시행착오를 공유하고 서로의 피드백을 적용하는 과정을 반복하며, 편하게 질문하고 의견을 나눌 수 있는 신뢰를 쌓고자 한다.

A&D 등의 팀 활동에서는 제한된 시간 안에 하나의 목표를 완성하는 경험을 하고 싶다. 각자의 강점에 따라 역할을 나누고 진행 상황과 판단 근거를 공유하며, 문제가 발생했을 때 팀이 합의한 목표에 맞게 분석 방향을 조정하는 협업 방식을 배우고자 한다. 이러한 경험을 바탕으로 활동이 끝난 뒤에도 취약점 분석과 새로운 보안 문제에 함께 도전하며 서로의 성장을 도울 수 있는 관계를 이어가고 싶다.

## 목표를 이루기 위한 행동

1. 각 미션을 시작하기 전에 활동이 나의 목표와 어떻게 연결되는지 생각하고, 학습할 내용과 기대 결과를 정리한다.
2. AI를 활용할 때는 먼저 기대하는 결과와 판단 기준을 정하고, 중간 결과가 목표에 맞는 방향으로 진행되는지 실제 코드와 바이너리의 동작, 신뢰할 수 있는 자료와 비교해 확인한다. 병목이 발생하면 같은 요청을 반복하기보다 잘못된 가정, 누락된 정보, 접근 방법 가운데 원인을 빠르게 찾아 수정하고, 필요한 정보와 다음 작업을 구체적으로 다시 지시한다.
3. 혼자 해결하기 어려운 부분은 교육생과 수료생에게 적극적으로 질문하고, 서로의 분석 방법을 비교하며 받은 피드백을 실제 문제 해결 과정에 적용한다.
4. 활동이 끝나기 전까지 여러 미션에서 배운 내용을 실제 취약점 분석에 적용하고, 분석 과정과 시행착오, 결과를 블로그 글이나 보고서로 정리해 공유한다.

## 마치며

내가 되고 싶은 사람은 시스템 해킹과 펌웨어 분석에 대한 전문성을 바탕으로 임베디드 시스템의 보안 문제를 해결하고 사회에 기여하는 보안 연구자다.

나이츠프론티어 활동이 끝났을 때 새로운 네트워크 기기를 스스로 분석할 수 있는 역량과 보안 문제에 계속 도전할 동료를 얻는다면 이번 7개월을 성공적인 도전이었다고 판단할 수 있을 것 같다. 또한 여러 분야의 미션과 동료들의 경험을 통해 자동차 보안을 더 깊게 탐구할지, 보다 넓은 임베디드 시스템 보안으로 관심을 확장할지 판단할 근거를 얻고 싶다. 다양한 경험을 관심 분야에 연결하여 앞으로 집중할 진로와 학습 방향을 구체화하고, 배운 것을 실제 결과로 만드는 7개월을 보내고 싶다.
